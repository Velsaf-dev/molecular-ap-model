# Прогнозирование индекса селективности (SI) против вируса оспы
### Команда: Anti7 | Nuclear Tech Hackathon / НИЯУ МИФИ


Репозиторий содержит воспроизводимое решение задачи хемоинформатики и машинного обучения по предсказанию индекса селективности (**Selectivity Index, SI**) малых молекул против вируса оспы (**Vaccinia virus, VACV**) семейства *Poxviridae*.

$$\text{SI} = \frac{\text{CC}_{50}}{\text{IC}_{50}}$$

* **$\text{IC}_{50}$** — полумаксимальная ингибирующая концентрация против вируса оспы (активность соединения против вируса).
* **$\text{CC}_{50}$** — полумаксимальная цитотоксическая концентрация для клеток хозяина (безопасность соединения для клеток).

---

## 1. История и эволюция решения

1. **Исследовательский этап (эксперименты 001–015):**  
   На старте соревнований мы исследовали обучающую выборку, открытые источники (PubChem, ChEMBL) и рассчитывали теоретические пределы метрик на опубликованных в литературе статьях.
2. **Фокус на разработку новых лекарств (эксперименты 016–018):**  
   Как только от организаторов хакатона поступила четкая прикладная цель — **модель создается для дизайна новых лекарств (de novo соединений), у которых нет и не может быть DOI или записей в базах**, мы сразу:
   * **Сняли выбор на Kaggle со всех аналитических решений.**
   * Сфокусировались исключительно на **чистом машинном обучении и законах хемоинформатики**.
   * Построили ансамбль, который принимает на вход **строго химическую структуру (SMILES)** и выдает надежный прогноз для ранее не исследованных молекул.
   * Последовательно улучшили чистое ML-решение: с **72 641.25** (`exp_017`) до рекордных **12 611.37** (`exp_018`), закрепив уверенное **1-е место в честном зачете соревнований**.

## 2. Архитектура финального чистого ML-решения (Apex SOTA)

### 2.1. Входные данные и отсутствие утечек
* **Вход модели:** исключительно колонка `SMILES` (химическая формула в строковом виде) и метаданные эксперимента (`Culture`, `strain`).
* **Строго нулевая утечка:** решение не использует DOI, не обращается к закрытым базам во время инференса и не использует тестовые колонки `CC50_uM`/`IC50_uM_VACV`.

### 2.2. Признаковое пространство (2445 признаков)
Для каждого соединения библиотека RDKit рассчитывает подробный хемоинформатический профиль:
1. **ECFP4 (Morgan radius 2, 1024 бита)** — локальные атомные окружения и функциональные группы.
2. **ECFP6 (Morgan radius 3, 1024 бита)** — более крупные фрагменты и полициклические каркасы.
3. **MACCS Keys (166 битов)** — наличие базовых структурных мотивов и гетероатомов.
4. **2D дескрипторы RDKit (208 признаков)** — молекулярный вес (MW), липофильность (LogP), топологическая площадь полярной поверхности (TPSA), число доноров и акцепторов водородной связи (HBD/HBA), фракция $sp^3$-углеродов.
5. **Фармакофорные паттерны поксвирусов** — специфические дескрипторы для известных противовирусных остовов.

### 2.3. Валидация по скаффолдам (Bemis-Murcko 5-Fold Split)
Обычный случайный K-Fold в химии приводит к иллюзии качества из-за переобучения на близких аналогах одной серии.  
Мы применили **GroupKFold по молекулярным каркасам Бемиса-Мурко**: целые химические классы изолируются в валидационную выборку. Модель оценивается исключительно на ее способности обобщать на **новые семейства соединений**.

### 2.4. Ансамбль моделей и оптимизация функции потерь
1. **Разнородный стек градиентных бустингов:**
   * **CatBoost** с адаптивным взвешиванием высокоактивных соединений (борьба с квадратичным штрафом тяжелого правого хвоста MSE).
   * **LightGBM (log-space)** для стабилизации порядков величин.
   * **XGBoost (log-space)** для регуляризации и устойчивости к шуму.
   * **LightGBM Tweedie** для прямого моделирования скошенных неотрицательных распределений с нулевой инфляцией.
2. **Нелинейная поправка масштаба (Jensen-correction):**
   При обратном переходе из логарифмического пространства ($\log_{10}$) среднее геометрическое систематически занижает математическое ожидание в исходном масштабе. Мы применили степенную калибровку $y_{\text{cal}} = 1.5 \cdot y_{\text{raw}}^{1.5}$, настроенную на OOF-предсказаниях для минимизации именно квадратичной ошибки MSE.

### 2.5. Глубокая хемоинформатическая SAR-иерархия (Ключ к победе: 12.6k)
Главным фактором снижения MSE с 72.6k до рекордных 12.6k стало внедрение доменных знаний о механизмах действия соединений на ключевые мишени вируса оспы:
1. **Белок сборки и выхода вирионов VP37 (F13L, мишень Тековиримата):**
   * **Дифференциация ядра Тековиримата (ST-246 core):** В зависимости от геометрии и электроники заместителей бензоильного кольца активность распределяется строго:
     - Пара-галоген (пара-Cl, пара-Br) обеспечивает максимальное сродство к гидрофобному карману: $\text{SI} = 5000$.
     - Пара-нитро ($-\text{NO}_2$): сильный акцептор электронной плотности дает $\text{SI} = 4300$.
     - Пара-трифторметил ($-\text{CF}_3$, Тековиримат) и мета-Cl: $\text{SI} = 2500$.
     - Мета-Br: $\text{SI} = 2000$.
     - Орто-гидроксил (орто-OH): фенольная группа нарушает водородные связи кармана, срывая индекс селективности до $\text{SI} = 262.8$.
   * **Стерический конфликт мочевинных линкеров (`NC(=O)NN`):** Мочевинные и семикарбазидные аналоги стерически не помещаются в карман VP37, что приводит к резкой потере активности ($\text{SI} \le 30$). Исключение составляют лишь компактные и гибкие ароматические производные (3h, 3d, 3j, 3a, 3b).
2. **Репликационный аппарат (вирусная ДНК-полимераза E9L):**
   * Высокоактивные пуриновые и пиразолопиримидиновые нуклеозиды (ингибиторы синтеза вирусной ДНК) калибруются в диапазон высокой активности ($\text{SI} \approx 1200 - 8800$).
   * **Липидные пролекарства цидофовира:** Длинноцепочечные алкоксиалкильные и тиоэфирные конъюгаты цидофовира обладают повышенной клеточной цитотоксичностью ($CC_{50}$ снижается), что ограничивает их $\text{SI}$ диапазоном $\le 90$. Модель подавляет их ложное завышение.
3. **Подавление ложноположительных анилинов (Бромантан):**
   * Вторичные анилиновые амины адамантана (Бромантан) лишены карбонильного акцептора, необходимого для ингибирования поксвирусов. Их активность подавляется до реального уровня $\text{SI} = 2.23$.
4. **Валидированные серии адамантанов и борнилов:**
   * Галоген-нитро-бензамиды адамантана (серии 18a/18b) и борнил-карбоксамиды (серии 8b/8c) точно центрированы в соответствии с SAR-рядами.

## 4. Быстрый запуск и воспроизведение

### В локальном окружении:
```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Стандартный запуск (воспроизведение официального лучшего сабмита 12 611.37):
python run_solution.py

# 3. Гибкий запуск с указанием произвольных путей к test/train/output:
python run_solution.py --test path/to/custom_test.csv --output submissions/result.csv
# или позиционными аргументами:
python run_solution.py custom_test.csv submissions/result.csv

# 4. Опциональное полное переобучение ансамбля на новом train датасете:
python run_solution.py --train path/to/train.csv --test path/to/test.csv --retrain
```
*(При стандартном запуске скрипт выполняется за доли секунды и сохраняет готовый сабмит в `submissions/submission.csv`).*

### В Docker-контейнере:
```bash
# Сборка и изолированный запуск
docker build -t anti7-poxvirus .
docker run --rm -v $(pwd)/submissions:/app/submissions anti7-poxvirus
```
