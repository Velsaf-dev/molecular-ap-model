# Прогнозирование индекса селективности (SI) малых молекул против вируса оспы (Vaccinia virus)
### Nuclear Tech Hackathon / AIX НИЯУ МИФИ

Репозиторий содержит законченное, воспроизводимое решение задачи регрессии для предсказания индекса селективности (**Selectivity Index, SI**) малых молекул против вируса осповакцины (**Vaccinia virus, VACV / VV**) семейства *Poxviridae*.

$$\text{SI} = \frac{\text{CC}_{50}}{\text{IC}_{50}}$$

* **$\text{IC}_{50}$** — полумаксимальная ингибирующая концентрация против вируса оспы (чем меньше, тем эффективнее препарат).
* **$\text{CC}_{50}$** — полумаксимальная цитотоксическая концентрация для клеток хозяина (чем больше, тем безопаснее соединение).

## 2. Ключевые компоненты решения

### Модуль А. Сбор и обогащение данных (Data Mining Pipeline)
* Автоматический парсинг базы **ChEMBL** (более 800 ассаев по мишеням семейства *Poxviridae*: Vaccinia, Cowpox, Monkeypox, Variola).
* Извлечение значений противовирусной активности ($\text{IC}_{50}$, $\text{EC}_{50}$) и цитотоксичности ($\text{CC}_{50}$), расчет $\text{SI}$ и привязка **DOI** публикаций.
* **Строжайшая защита от утечки (Data Leakage):** Все структуры из `test.csv` (по каноническим SMILES и InChIKey) автоматически исключены из обучающей выборки (отфильтровано 77 молекул-дубликатов).
* Итоговый расширенный датасет сохранен в `data/external_poxvirus_dataset.csv` со стандартизированными полями: `smiles`, `IC50`, `CC50`, `SI`, `doi`.

### Модуль Б. Хемоинформатическая предобработка (Cheminformatics Preprocessing)
* Обессоливание (выделение наибольшего органического фрагмента, удаление противоионов и растворителей через `rdMolStandardize.LargestFragmentChooser`).
* Нейтрализация зарядов молекул (`rdMolStandardize.Uncharger`).
* Канонизация SMILES-нотаций через RDKit.
* Агрегация повторных измерений для одинаковых структур с использованием робастной статистики (медиана).

### Модуль В. Извлечение молекулярных признаков (Feature Engineering)
Для каждой молекулы извлекается расширенный вектор из **2431 признака**:
1. **Morgan Fingerprints (ECFP4)** — радиус 2, 1024 бита (локальное химическое окружение).
2. **Morgan Fingerprints (ECFP6)** — радиус 3, 1024 бита (расширенные функциональные мотивы).
3. **MACCS Structural Keys** — 166 битов (экспертные структурные ключи).
4. **Физико-химические дескрипторы RDKit (217 признаков)** — молекулярная масса, TPSA, MolLogP, число H-доноров/акцепторов, число ароматических/алифатических колец, QED, фракция $sp^3$-углеродов, топологические индексы (Кира, Баллабана, Берца) и поверхностные дескрипторы VSA.
5. Фильтрация околонулевой дисперсии (`VarianceThreshold`) для устранения неинформативных битов.

### Модуль Г. Обучение, трансформация таргета и валидация
* **Трансформация таргета:** обучение моделей ведется на $\log_{10}(\text{SI} + 0.1)$, что устраняет экспоненциальный правосторонний скос распределения и корректно учитывает неактивные молекулы ($\text{SI} = 0$).
* **Схема валидации (Bemis-Murcko Scaffold Split):**
  * Строгий Group 5-Fold кросс-валидационный сплит по химическим каркасам Бемиса-Мурко (`MurckoScaffold`).
  * Полностью исключает утечку гомологичных аналогов между обучающими и валидационными фолдами, гарантируя генерализацию на новые химические семейства.
* **Модельный ансамбль:**
  * **CatBoost Regressor** (depth=5, l2_reg=3.0)
  * **LightGBM Regressor** (depth=5, num_leaves=24)
  * **XGBoost Regressor** (depth=4)
  * Блендинг с весами: $0.40 \cdot \text{CatBoost} + 0.35 \cdot \text{LightGBM} + 0.25 \cdot \text{XGBoost}$.

### Модуль Д. Постобработка и генерация сабмита
* Усреднение прогнозов всех 5 фолдов ансамбля (всего 15 обученных моделей).
* Обратное потенцирование: $10^{\hat{y}} - 0.1$.
* Физическое пороговое отсечение отрицательных величин ($\max(0.0, \hat{y})$).
* Экспорт в формат соревнования (`submissions/submission.csv`).

## 3. Результаты кросс-валидации (Bemis-Murcko Scaffold CV)

На строгой 5-фолдовой кросс-валидации по химическим каркасам ансамбль продемонстрировал высокие и стабильные метрики обобщающей способности:

| Метрика | Значение на OOF (Out-Of-Fold) |
|---|---|
| **Spearman Rank Correlation ($\rho$)** | **0.5874** |
| **Pearson Correlation ($r$)** | **0.5888** |
| **$R^2$ ($\log_{10}$)** | **0.3467** |
| **MAE ($\log_{10}$)** | **0.7650** |
| **RMSE ($\log_{10}$)** | **0.9901** |

## 4. Воспроизводимость (Запуск одной командой)

### Установка окружения
```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Запуск полного пайплайна
```bash
bash run_pipeline.sh
```

Скрипт автоматически:
1. Выполняет объединение датасетов и строгую валидацию на утечки (`Assert 0 leak`).
2. Проводит стандартизацию и расчет 2431 дескриптора RDKit + ECFP4/6 + MACCS.
3. Обучает 15 моделей ансамбля на 5 фолдах Bemis-Murcko Scaffold Split.
4. Выполняет инференс для `test.csv` и сохраняет итоговый файл: `submissions/submission.csv`.
