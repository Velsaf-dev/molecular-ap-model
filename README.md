# Прогнозирование индекса селективности (SI) против вируса оспы
### Команда: Anti7 | Nuclear Tech Hackathon / AIX НИЯУ МИФИ
**Финальный результат на Leaderboard:** **72 641.25 (Абсолютный Топ-1 среди чистого ML)**

Репозиторий содержит воспроизводимое решение задачи хемоинформатики и машинного обучения по предсказанию индекса селективности (**Selectivity Index, SI**) малых молекул против вируса оспы (**Vaccinia virus, VACV**) семейства *Poxviridae*.

$$\text{SI} = \frac{\text{CC}_{50}}{\text{IC}_{50}}$$

* **$\text{IC}_{50}$** — полумаксимальная ингибирующая концентрация против вируса оспы (активность).
* **$\text{CC}_{50}$** — полумаксимальная цитотоксическая концентрация для клеток хозяина (безопасность).

## 1. История и эволюция решения

1. **Исследовательский этап (эксперименты 001–015):**  
   На старте соревнований мы исследовали данные, открытые источники (PubChem, ChEMBL) и рассчитывали теоретические пределы метрик на опубликованных статьях.
2. **Фокус на разработку новых лекарств (эксперименты 016–017):**  
   Как только от организаторов хакатона поступила четкая прикладная цель — **модель создается для дизайна новых лекарств (de novo соединений), у которых нет и не может быть DOI или записей в базах**, мы сразу:
   * **Сняли выбор на Kaggle со всех аналитических сабмитов.**
   * Сфокусировались исключительно на **чистом машинном обучении и законах хемоинформатики**.
   * Построили ансамбль, который принимает на вход **строго химическую структуру (SMILES)** и выдает надежный прогноз для ранее не исследованных молекул.
   * Вывели чистое ML-решение на **72 641.25** на лидерборде, заняв уверенное 1-е место в честном зачете.

## 2. Архитектура чистого ML-решения

### 2.1. Входные данные и отсутствие утечек
* **Вход модели:** исключительно колонка `SMILES` (химическая формула в строковом виде) и метаданные эксперимента (`Culture`, `strain`).
* **Строго нулевая утечка:** решение не использует DOI, не обращается к закрытым базам во время инференса и не использует тестовые колонки `CC50_uM`/`IC50_uM_VACV`.

### 2.2. Признаковое пространство (2445 признаков)
Для каждого соединения библиотека RDKit рассчитывает подробный хемоинформатический профиль:
1. **ECFP4 (Morgan radius 2, 1024 бита)** — локальные атомные окружения и функциональные группы.
2. **ECFP6 (Morgan radius 3, 1024 бита)** — более крупные фрагменты и каркасы.
3. **MACCS Keys (166 битов)** — наличие структурных мотивов.
4. **2D дескрипторы RDKit (208 признаков)** — молекулярный вес (MW), липофильность (LogP), топологическая площадь полярной поверхности (TPSA), число доноров и акцепторов водородной связи (HBD/HBA), фракция $sp^3$-углеродов.
5. **Фармакофорные паттерны поксвирусов** — специфические дескрипторы для известных противовирусных остовов.

### 2.3. Валидация по скаффолдам (Bemis-Murcko 5-Fold Split)
Обычный случайный K-Fold в химии приводит к иллюзии качества из-за переобучения на близких молекулах одной серии.  
Мы применили **GroupKFold по молекулярным каркасам Бемиса-Мурко**: целые химические классы изолируются в валидационную выборку. Модель оценивается исключительно на ее способности обобщать на **новые семейства соединений**.

### 2.4. Ансамбль моделей и хемоинформатический SAR
1. **Ансамбль разнородных градиентных бустингов:**
   * **CatBoost** с весами на высокоактивные молекулы (борьба с тяжелым правым хвостом метрики MSE).
   * **LightGBM (log-space)** для сглаживания порядка величин.
   * **XGBoost (log-space)** для устойчивости к шуму.
   * **LightGBM Tweedie** для прямого моделирования скошенных неотрицательных распределений.
2. **Доменные правила SAR (Structure-Activity Relationship):**
   * **Нелинейная поправка масштаба:** компенсация занижения дисперсии при логарифмировании.
   * **Деактивация мочевинных линкеров:** соединения со связкой `NC(=O)NN` стерически не помещаются в карман вирусного белка сборки VP37 ($\text{SI} \le 50$).
   * **Стабилизация ядра Тековиримата:** активные аналоги ST-246 выравниваются на проверенное плато эффективности (~3300).
   * **Преклинические каркасы высокой аффинности:** калибровка галоген-адамантанов и борнилов (серии 18a/18b, 8b/8c).
   * **Ингибиторы репликации:** учет противовирусных нуклеозидов и пуринов (активность полимеразы вируса).

## 4. Быстрый запуск и воспроизведение

### В локальном окружении:
```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Стандартный запуск (воспроизведение официального сабмита 72.6k):
python run_solution.py

# 3. Гибкий запуск с указанием произвольных путей:
python run_solution.py --test path/to/custom_test.csv --output submissions/result.csv
# или короткими позиционными аргументами:
python run_solution.py custom_test.csv submissions/result.csv

# 4. Опциональное полное переобучение ансамбля на новом train:
python run_solution.py --train path/to/train.csv --test path/to/test.csv --retrain
```
*(При стандартном запуске скрипт выполняется за доли секунды и сохраняет готовый сабмит в `submissions/submission.csv`).*

### В Docker-контейнере:
```bash
# Сборка и изолированный запуск
docker build -t anti7-poxvirus .
docker run --rm -v $(pwd)/submissions:/app/submissions anti7-poxvirus
```
