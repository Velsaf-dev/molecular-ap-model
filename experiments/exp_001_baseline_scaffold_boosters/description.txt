ЭКСПЕРИМЕНТ №001: Baseline Scaffold-Split Gradient Boosting Ensemble
================================================================================
Дата: 2026-11-07
Автор/Модель: CatBoost + LightGBM + XGBoost Ensemble
Статус: Завершен
Результат на Public Leaderboard: 1 983 710.26126 (15 место)

1. ОПИСАНИЕ ПОДХОДА:
- Данные: Обучающая выборка train_v2.csv (320 соединений) + внешний датасет ChEMBL (после дедупликации и строгой фильтрации пересечений с test.csv).
- Валидация: 5-Fold GroupKFold по Bemis-Murcko молекулярным скаффолдам (гарантия отсутствия утечки химических серий между фолдами).
- Признаки: 2347 молекулярных дескрипторов (ECFP4 1024 бит, ECFP6 1024 бит, MACCS-ключи 166 бит, 208 физико-химических дескрипторов RDKit 2D).
- Модели: 5 фолдов x 3 архитектуры (всего 15 моделей):
  * CatBoostRegressor
  * LightGBMRegressor
  * XGBRegressor
- Обучение: В логарифмической шкале log10(SI + 0.1) с функцией потерь RMSE.
- Пост-процессинг: Наивное обратное преобразование y_pred = 10^z - 0.1.

2. ДИАГНОСТИКА И ПРИЧИНА СКОРА 1.98M:
- Из-за неравенства Йенсена (Jensen's inequality) обратное потенцирование дало геометрическое среднее (медиану).
- Среднее значение по тесту составило всего 28.05 (при реальном среднем ~245).
- Ошибка на редких высокоселективных молекулах (SI > 1000) дала колоссальный штраф по метрике MSE, определив скор около 1.98 млн.
